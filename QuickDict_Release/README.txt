============================================================
                  QuickDict (Windows 10 / 11)
============================================================

Быстрый переводчик выделенного текста по горячей клавише.

1. БЫСТРЫЙ СТАРТ
- Запустите QuickDict.exe (или RUN.bat).
- В системном трее (возле часов) появится значок программы.
- Выделите любой текст в любой программе (браузер, чат, PDF, код)
  и нажмите сочетание клавиш:

      Win + Shift + Q

- В правом нижнем углу экрана появится стильное окно с переводом.

2. УПРАВЛЕНИЕ
- Наведение мыши на окно перевода: таймер автозакрытия замораживается,
  пока курсор находится на окне.
- Клик по крестику (x) в правом верхнем углу окна: мгновенно закрывает перевод.
- Клик по значку в трее: открывает контекстное меню (Настройки / Выход).
- Двойной клик по значку в трее: открывает Настройки.

3. НАСТРОЙКИ (SETTINGS.bat)
- Основной сервис: Google Translate (бесплатно, работает сразу) или OpenRouter (нейросети).
- Язык перевода: ru, en, de, zh, es, fr, ja и любые другие.
- Таймаут окна: настраиваемое время показа перевода (по умолчанию 5 секунд).
- Автозапуск: запуск вместе с Windows при старте системы.

4. УДАЛЕНИЕ (UNINSTALL.bat)
- Скрипт UNINSTALL.bat полностью очищает реестр автозапуска, сохраненные
  настройки и ключи.
